# Lab 2 - Dart Essentials Practice Lab

## Objective
Practice core Dart language features including:
- Basic syntax & data types
- Collections (List, Set, Map) & operators
- Control flow (if/else, switch, loops) & functions
- OOP basics (classes, constructors, inheritance)
- Async/await, Futures, null safety, and streams

## Exercises Included

### Exercise 1: Basic Syntax & Data Types
- Declare variables: int, double, String, bool
- Use print() and string interpolation
- Output: Variable types and values with calculations

### Exercise 2: Collections & Operators
- List operations (indexing, length, contains)
- Set for unique values
- Map for key-value pairs
- Spread operator (...) for combining collections
- Ternary operator (?:)

### Exercise 3: Control Flow & Functions
- if/else block for grading
- switch case for day of week
- for loop, for-in loop, forEach
- Normal and arrow syntax functions

### Exercise 4: Intro to OOP
- Car class with properties and methods
- Named constructor
- Inheritance (ElectricCar extends Car)
- Method overriding

### Exercise 5: Async, Future, Null Safety & Streams
- Async function with await
- Future.delayed() for simulated loading
- Null coalescing operator (??)
- Force unwrap (!)
- Stream and yield

## Running the Program

```bash
# From the Lab2 folder
dart lab2_dart_essentials.dart
```

Or from parent folder:
```bash
dart Lab2/lab2_dart_essentials.dart
```

## Expected Output
The program prints results for all 5 exercises in sequence, showing:
- Variable values and types
- Collection operations
- Control flow results
- OOP object behavior
- Async/await completion and stream values
