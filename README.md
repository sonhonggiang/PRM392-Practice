# PRM393 Dart Demo

Bài mẫu Dart console tương tự hình bạn gửi: chuỗi, ký tự xuống dòng, nội suy chuỗi, `runtimeType`, `toString()` và `int.parse()`.

## Chạy chương trình

```powershell
dart run
```

Entrypoint mặc định là `bin/prm393_dart_demo.dart`. File `bin/main.dart` được giữ lại như một bản sao tham khảo.
